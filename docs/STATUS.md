# Preview status

This repository contains a complete candidate source tree, not a finished Windows
release. Private project adapters have been separated in the exported code only.
The source includes itch intake/evidence, plans/refactor/review/acceptance,
research, learning, Suggested/manual scout, public Inspiration readers, suggestive
typing, Jev/Mercury, Browse, T3 chats/handoffs/attachments, DumbBridge, completion
GIFs/privacy/sharing/webhooks, generic Git/source/MCP, native and phone modules.

Private analytics, authored edit/batch tools and captured-account feeds are absent.
Posting notes accept manually supplied links and do not claim verification.
Fresh defaults have no projects, records or connections.

## Checks

Check the private-preview workflow for exact results. A successful candidate
includes BUILD-VALIDATION.json with its executable start/stop check. Compilation,
tests and packaging remain pending until those checks pass.
CI uses disposable data and synthetic fixtures, never a connected account.

## Still required before calling this a release

- Full desktop and phone browser QA across the changed public navigation and first run.
- A clean Windows install/restart/upgrade/removal check of the exact packaged build.
- Real Jev/Mercury/T3/Discord/webhook checks using the tester's own connections.
- Capture/clipboard/OCR/replay and animated-card checks on a real Windows desktop.
- Archive and extracted executable review, signing decision, and owner acceptance.

Packaging automation saves a private draft release for review after its checks
pass. It never publishes that draft or changes repository visibility. No signing or SmartScreen trust
is claimed. Passing mocked service tests does not validate live integrations.
