# Portable repro brief

From a private DumbBridge draft choose **Make repro brief**, edit the five fields, and download the complete UTF-8 Markdown. Use Observed for the actual result and error/log excerpt; Environment and Steps can include your own useful links. Unknown fields stay unknown. Long panel values are labeled excerpts: inspect the complete file before sharing.

Source is omitted by default. Include source opts into captured message text and safe attachment filename/type metadata; it does not download or embed media. Omit source removes these again. Automatic source IDs and source links are not added. User-authored fields, filenames and included source text can still contain private information; this is not a general redaction tool. Discord attachment download URLs are removed. Review and edit your fields, or omit source, before sharing.

No provider is called, itch created or external message sent. A stale modal edit is retained separately without overwriting the current brief; download the recovered edit from the private panel and retry. Old cards without application binding require a fresh invocation. Drafts and briefs remain local app data.
