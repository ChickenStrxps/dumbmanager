# Private follow-ups

Choose **Save follow-up** from a private message draft, enter a note and optional excerpt, review it, then confirm. This creates a local bookmark; it does not capture an itch, notify anyone, call a provider or send to T3. The review copy stays in the intake draft until Confirm or Cancel clears it. Saving the bookmark and clearing the review are one transaction.

Invoke `/dumbbridge inbox:true` with no message or attachment to reopen your own items from a permitted server or DM. Current user/channel allowlists still apply. The source link may no longer be accessible; a captured excerpt is not live content. The workspace must be reachable. App/actor ownership is enforced separately from the current invocation channel. Original intake controls stay bound to their original app, channel and server.

Pages contain ten items. Keep at most 200 per app/user; a full inbox rejects new saves without evicting older work. Mark done/reopen, edit the note, or delete the bookmark. Deletion removes the bookmark's note and excerpt, not the original intake draft or source message. Private bookmark content is not retained in replay receipts. Recreating a deleted bookmark gets a new identity, so old controls cannot change it.

Registration is explicit: preview and re-register the two existing named commands in Settings to publish the new optional inbox argument. This change does not register commands or start a listener automatically. No real Discord delivery is established by local fixture tests.
