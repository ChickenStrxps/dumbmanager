# Plugins

Open **Plugins** in the sidebar to discover tools and manage the local shelf.
DumbVoice and DumbLighting appear first with stars; DumbEffects is marked planned
until a package is available. Search checks the official MCP Registry and GitHub.
APIs link to a small curated set of official documentation. These are bounded
results, not a complete marketplace. Popularity uses GitHub stars where available;
the MCP Registry does not supply installation counts.

**For this project** reads only bounded root manifests from the registered project
folder. It shows the detected stack and matches tool descriptions and tags. Only
the search text or a detected stack keyword reaches the public search services;
project paths, source code and account settings stay local.

The **+** control adds an MCP, API or library reference to the DumbManager shelf.
A saved reference retains its source and setup details. It does not install a
project dependency, run an MCP server or change another client's configuration.

For a local DumbVoice package, select a built folder containing `DumbVoice.exe`
and `transcribe.py`. For DumbLighting, select its six HTML effects. Installation
copies these files to new app-owned package storage. **Open package folder** lets
you run the app or import the effects in SignalRGB. Copying never executes files.
Removing a shelf entry keeps its package files and original settings intact.

**Auto install via T3** shows the exact destination selected in **Working on**.
Use **Change in Working on** to choose and pin another context. **Send install
request to T3** explicitly sends setup instructions to that thread. An uncertain
delivery retains its tool, project, destination and request key for a safe retry.
Check the thread before clearing a request. This button delegates installation;
it does not claim that an accepted message is a completed installation.

Prerequisite checks use Windows uninstall registrations and PATH. Portable apps,
speech engines and models can be checked at user-selected locations. A found
registration or file does not verify its version, model compatibility or hardware.
SignalRGB is a separate desktop application; it is not silently installed.
DumbVoice's native whisper.cpp path requires an executable and compatible English
model; Python is optional for other engines. The setup request asks the thread to
verify current publisher instructions, preserve settings and report any remaining
manual requirements. It does not authorize recording audio or changing T3's own
MCP configuration.

The turtle background uses the existing aquarium clock and motion controls.
Twelve lazy glyph poses occupy approximately 6.8 MiB; steady frames blend two
cached tiles. Hidden pages and reduced-motion mode pause animation.
